# 라우터 few-shot 후보 (MVP1 — 3라우트)

> 용도: 라우터 분류 정확도가 기준(18/20) 미달일 때 ROUTER_PROMPT에 삽입할 예시.
> 코드 반영은 Claude Code/Codex 담당. eval 결과에서 오분류된 유형부터 추가한다.

## knowledge_query

- "개완으로 차 우리는 법 알려줘"
- "동아리방 사용 규칙이 뭐야?"
- "25-1 예산안에서 다과 지출 얼마였어?"
- "홍보부스 준비물 체크리스트 어디 있어?"
- "작년 가을 세미나에서 어떤 차 다뤘어?"

## handover_query

- "신임 회장이 학기 초에 해야 할 일 알려줘"
- "총무 처음 맡았는데 뭐부터 챙겨야 해?"
- "회장직 물려받으면서 확인할 문서 목록 줘"
- "세미나 담당 인수인계 받을 때 주의할 점?"
- "다음 운영진한테 넘겨줄 자료 정리해줘"

## unclear

- "그거 있잖아 그거"
- "음 뭐부터 물어봐야 하지"
- "저번에 말한 거 어떻게 됐어?"
- "이거 처리 좀"
- "다정 관련해서 하나만"

## 경계 케이스 (오분류 주의)

- "인수인계 문서 양식 어디 있어?" → **knowledge_query** (문서 위치 질문 — 인수인계 종합 아님)
- "예산안 작성 규칙 알려줘" → **knowledge_query** (MVP2 전까지 budget_query 없음)
- "신임 부원 모집 일정이 언제야?" → **knowledge_query** ("신임"만으로 handover 아님)
